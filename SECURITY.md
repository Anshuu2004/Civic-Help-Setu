# Security Policy

## Supported Versions

Currently, the `main` branch (latest release) is supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within CivicBridge, please send an e-mail to the maintainers instead of opening a public issue. We take all security vulnerabilities seriously and will work to resolve them as quickly as possible.

Please provide:
- A description of the vulnerability
- Steps to reproduce
- Potential impact

We will try to acknowledge your report within 48 hours.
